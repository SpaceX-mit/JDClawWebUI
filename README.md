# JDClawWebUI

基于 OpenClaw 的现代化 AI 助手 WebUI，融合腾讯 QClaw、飞书 Claw、有道龙虾 AI 的设计理念。

## 特性

### 🎨 设计特点
- **现代化界面**: 简洁优雅的设计风格
- **深色模式**: 支持亮色/暗色/自动主题切换
- **专注模式**: 隐藏侧边栏，沉浸式对话体验
- **响应式布局**: 适配各种屏幕尺寸

### ⚡ 功能特点
- **实时流式响应**: 即时显示 AI 生成内容
- **命令面板**: 快速访问所有功能 (Ctrl+K)
- **会话管理**: 轻松创建、切换、删除对话
- **多模型支持**: 支持 Claude、GPT 等多种模型
- **多助手**: 支持主助手、代码助手等多种角色
- **附件上传**: 支持图片、文件上传
- **Markdown 渲染**: 代码高亮、格式美化

### ⌨️ 快捷键
| 快捷键 | 功能 |
|--------|------|
| Ctrl+K | 打开命令面板 |
| Ctrl+N | 新建会话 |
| Ctrl+. | 切换专注模式 |
| Shift+Enter | 换行 |
| Enter | 发送消息 |

## 技术栈

- **框架**: Lit (Web Components)
- **构建**: Vite
- **语言**: TypeScript
- **样式**: CSS Variables + Shadow DOM

## 开发指南

### 添加新组件
1. 在 `src/components/` 创建新的 `.ts` 文件
2. 使用 Lit 的 `@customElement` 和 `@property` 装饰器
3. 在 `jd-app.ts` 中导入并使用

### 添加新功能
1. 在 `src/types/index.ts` 中添加类型定义
2. 在相应的组件中实现功能
3. 更新事件处理流程

### 样式指南
- 使用 CSS Variables 定义主题变量
- 在组件的 `static styles` 中编写样式
- 支持深色模式: 使用 `[theme="dark"]` 选择器
